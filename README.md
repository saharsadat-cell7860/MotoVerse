# MotoVerse
A modern and responsive motorcycle showroom website developed collaboratively using Bootstrap, HTML, CSS, and JavaScript.
# 🏍️ MotoVerse | Premium Motorcycle Showroom

MotoVerse is a modern and responsive motorcycle showroom website built with **HTML, CSS, Bootstrap 5, and JavaScript**.

The website is designed to provide a clean and interactive experience for users who want to explore motorcycles, view detailed information, and book a test ride.

---

## 🚀 Features

* Responsive design for desktop, tablet, and mobile
* Modern dark-themed UI
* Glassmorphism navigation bar
* Fixed navbar with active page states
* Motorcycle collection and filtering
* Motorcycle details section
* About MotoVerse section
* Contact and test ride forms
* Interactive Bootstrap components
* Smooth scrolling
* Scroll reveal animations
* Hover effects and transitions
* Form validation
* Mobile-friendly navigation
* Reusable CSS and JavaScript

---

## 📄 Pages

The website contains five main pages:

### 🏠 Home

Introduces MotoVerse with:

* Hero section
* Featured motorcycles
* Motorcycle categories
* Why Choose MotoVerse
* Test Ride CTA

### 🏍️ Motorcycles

Displays the motorcycle collection with category filters:

* All
* Sport
* Cruiser
* Adventure
* Classic

### ⚙️ Details

Shows detailed information about a selected motorcycle, including:

* Price
* Top speed
* Engine size
* Transmission
* Fuel capacity
* Performance features

### 👥 About

Introduces MotoVerse and includes:

* Company information
* Statistics
* Core values
* Rider-focused content

### 📩 Contact

Provides:

* Contact information
* Showroom details
* Contact form
* Motorcycle selection
* Test ride request
